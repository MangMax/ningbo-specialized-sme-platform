# 数据库访问

数据库读写使用 Drizzle 的类型化表定义、查询构造器和事务 API。禁止手写 SQL，包括通过 `sql` 模板、`sql.raw()`、`execute()`、底层驱动或独立文件执行的自编 SQL。

仅当项目所用 Drizzle 版本确实无法表达所需的数据库特性时，才可保留实现该特性的最小 SQL。先核对该版本的 API，再在实现旁说明具体特性和限制，外部值一律使用绑定参数。

运行 `pnpm verify:sql` 检查新增的 SQL 和驱动调用。基线中的历史命中用于防止回流。删除旧用法后运行 `node scripts/sql-guard.mjs --prune` 同步缩减基线；新增例外须说明构造器缺少的能力。
