# 03 — 整理版统代列:定位错位规律、修复或弃用

**What to build:** 处理 `经信局名单/公布文件名单全部整理版.xlsx` 里**已损坏的统代列**,并决定它在流程里的去留。

**Blocked by:** 01(安全阀落地后,整理版就不再能触发归并)

**Status:** ready

## 已查明的事实

- 「**创新型**」sheet:统代与工信部导出**不一致 969 / 5941 = 16.3%**。
- 「**专精特新**」sheet:仅 **1** 处不一致(`宁波市鄞州区规划设计院`,是真实的双来源冲突,不是错位)。
- 错位的样子:统代列**像是从另一份不同排序的表整列粘回**,行与行对不上。试点:
  - sheet1 `华创电子股份有限公司` 带的是 `可之(宁波)人工智能科技有限公司` 的统代 `91330203MA2GWNN84U`;
  - sheet1 `浙江翌德科技发展有限公司` 带的是 `华甬工程设计集团有限公司` 的统代 `913302001440841866`;
  - 而同一批企业在 **sheet2 里是对的**。

## 要做的

1. **定位机制**:确认「创新型」sheet 的统代列是不是整列错位(是 ±1 行、还是按另一个排序粘回)。给出**可复现的判据**(例如:对每个名称,其在 sheet1 的统代等于**另一个**名称的工信部统代——那批名称有什么排序特征)。
2. **决定去留**(择一并写理由):
   - **(a) 弃用**:整理版**不再作为统代来源**(仅保留作人工参考、不入流程)。理由:它有 16% 的错、又是手维护的;工信部导出才是统代权威。
   - **(b) 修复后限定用途**:订正「创新型」sheet,且今后只允许它作**候选**,必须经票 01 的佐证才生效。
   > 倾向 **(a)**:既然工信部导出覆盖了绝大部分企业,整理版对统代已无不可替代的作用;留着它就是留一个 16% 错的入口。
3. **判定「整理版当前是否还有不可替代的用途」**:统计有多少企业的统代**只能**从整理版得到(工信部与公布文件都给不出)。若为 0 或极少 → 直接弃用。
