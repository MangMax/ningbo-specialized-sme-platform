# [P1] RL-08 — 标注并筛选每个称号的首次认定企业

**级别：** scope:M — 基于既有认定事件计算企业×称号首次记录，范围明确。
**难度：** 中｜**主要难点：** 历史不完整和复核失败后重获批不能改变首次认定｜**建议模型：** magpie + DeepSeek

## Parent

[总规格 #14：专精特新企业名录规格](https://github.com/MangMax/ningbo-specialized-sme-platform/issues/14)

## What to build

用户能按企业和称号识别最早的正式认定事件，快速筛选并导出首次认定名单，且能核对首次年份和正式来源。

## Acceptance criteria

- [ ] 首次认定按企业×称号的最早正式认定事件计算。
- [ ] 复核通过不成为新的首次认定；复核失败后再次获批也不重置首次认定。
- [ ] 历史不完整时标为待确认，不把当前已导入数据里的最早年份冒充首次。
- [ ] 总表可筛选并导出首次认定企业，显示称号、年份和来源证据。
- [ ] 统计清楚标示企业数或企业×称号数。
