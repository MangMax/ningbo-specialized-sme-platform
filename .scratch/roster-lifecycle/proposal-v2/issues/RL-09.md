# [P1] RL-09 — 生成下一年度需要复核的企业清单

**级别：** scope:M — 在既有事件上计算目标年份复核清单，独立可验收。
**难度：** 中｜**主要难点：** 重新获批刷新复核锚点但不重置首次认定｜**建议模型：** magpie + DeepSeek

## Parent

[总规格 #14：专精特新企业名录规格](https://github.com/MangMax/ningbo-specialized-sme-platform/issues/14)

## What to build

用户选择下一年或指定年份后，可以按称号查看届时需要复核的有效企业，并能看到复核年份的计算依据和来源。

## Acceptance criteria

- [ ] 按用户确认的三年复核规则，从最近一次有效正式认定或通过复核的事件计算到期年份。
- [ ] 复核失败的资格不进入当前有效复核清单；后续重新获批刷新复核锚点但不改变首次认定。
- [ ] 清单支持目标年份和称号筛选，并显示企业、称号、到期年份、锚点事件、批次和来源。
- [ ] 年份、批次或历史事件证据不全时进入待确认列表，不靠文件名猜年份。
- [ ] 清单可导出，导出与页面筛选结果一致。
