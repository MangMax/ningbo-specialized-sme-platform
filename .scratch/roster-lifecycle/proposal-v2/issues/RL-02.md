# [P0] RL-02 — 导入历年小巨人名单并保留批次历史

**级别：** scope:M — 单一工作簿导入，范围清楚，需保留批次和原始来源。
**难度：** 中｜**主要难点：** 区分有效名单区域并让重复导入幂等｜**建议模型：** magpie + DeepSeek

## Parent

[总规格 #14：专精特新企业名录规格](https://github.com/MangMax/ningbo-specialized-sme-platform/issues/14)

## What to build

用户能将“经信局公布历年小巨人企业名单.xlsx”作为正式公布来源导入，并在企业名录中查看相应的小巨人认定批次和来源。重复企业只保留一个企业身份，但每次批次记录都保留。

## Acceptance criteria

- [ ] 名单字段只取工作簿中已确认的小巨人名单区域，不把旁侧备注或其它名单误读为企业记录。
- [ ] 按约定将第一批映射为 2019、第八批映射为 2026；当前源文件未含第八批时报告缺口，不生成虚构记录。
- [ ] 每一条源名单行均进入名录事件，或进入带原因的待核清单；不匹配平台导出不构成丢弃理由。
- [ ] 同一统一社会信用代码跨批次重复时企业去重，但各批次事件与来源证据保留。
- [ ] 同一来源重复导入不重复新增企业、事件或来源证据。
