# [P0] RL-05 — 将三张平台导出表保存为年度对照快照

**级别：** scope:M — 三张对照表共用一个快照导入规则，边界清楚。
**难度：** 中｜**主要难点：** 替换文件与相同文件重放要有不同且稳定的快照身份｜**建议模型：** magpie + DeepSeek

## Parent

[总规格 #14：专精特新企业名录规格](https://github.com/MangMax/ningbo-specialized-sme-platform/issues/14)

## What to build

用户每年导入三张工信部导出表后，可以识别每张表的采集时间和来源版本、查看当前快照与上一版差异，并在需要时追溯具体输入文件和行。

## Acceptance criteria

- [ ] 三张表分别作为平台现状对照源保存，不覆盖经信局公布的称号历史。
- [ ] 每次导入可查看采集/导入时间、称号、来源文件版本、记录数量和导入结果。
- [ ] 相同文件重放不会重复生成快照；替换文件形成可区分的新版本。
- [ ] 可以查看两个快照间新增、消失和字段变化，并追溯到原始行。
- [ ] 最新快照驱动当前平台存在状态；旧快照仍可用于解释年度变化。
