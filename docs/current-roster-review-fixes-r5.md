# #116 第五轮：失败时间与未知批次的可行归属

当前新任务使用 `current-roster-116-v6`；历史 v1–v5 摘要继续读取原版本，不修改任务或产物。

明确失败的结论年不依赖 batch 是否完整。`cycleFacts` 同时保留失败时间和归属缺口：前者用于既有跨周期同年恢复检查，后者继续约束本周期。2018 原周期 failed2025（batch 空）与新 award2025 的先后无法确定，仍待确认；补 batch、删除旧 award 或加入 passed 均不能证明恢复。严格更晚的真实 award 可消解该疑点。旧失败晚于新 award 且不同年时，仍遵循原周期隔离，不把旧失败自动适用于新周期。

未知 batch 的 award 具有明确的授予事实，但可能属于已知批次，也可能单独成批。聚合时保留各已知批次的裁定，并逐条检验未知 award 可以单独成批时的资格；不借未知 award 去恢复已知批次。未知复核仍作为各可能批次的适用性缺口。只有全部可能批次均有效时，才可证明合并任意授予事实也不会使其失效：各批的失败、缺口和期限已经独立满足；增加授予不会撤销这些有效依据。该检查无需枚举分区，也不创造实际 batch ID 或正式事件。

因此，2025 batch1/null 的正式新认定在2026执行均有效，加入 batch2 仍有效；一致正式 passed 加入同样有效的未知批次授予也不降级。反之，到期/null 与新认定混合时，不能把未知授予猜到同批并按最新日期吞掉到期事实；失败、未知复核结论、未知日期或不能消解的先后疑点继续待确认。未知 batch 的 passed 仍不能冒充恢复 award。
