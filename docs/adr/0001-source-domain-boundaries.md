写接缝复用统一导入的预检/提交/回执，由各来源校验自身载荷、完整性与不可变坐标；原归档和共享身份/版本/观察保持同事务，新增业务投影明确解释规则版本。需本地更正时保存独立的明确决定、依据及前后值，不回写伪造上游原值。读接缝按来源返回有类型字段、业务/版本/原观察引用、字段出处与规则版本、时点/完整性及未知/冲突；缺失、不适用、未验证和冲突不能以空结果混同。HTTP与MCP共享同一领域命令/读取，不暴露任意表字段写口。

共享身份仅处理当前MIIT的 `(interface, platformKey)` 命名空间；同编号跨接口不合并，缺键/冲突不按统代或名称强并。未来平台先明确来源系统、业务身份和跨URL关系；有依据证明两个URL是同一业务不同投影时可共享业务身份，观察与字段语义仍各自保留。

共享采集拥有传输、服务端凭据快照、预算、有限重试、分页骨架、取消/检查点。公共索引拥有稳定身份、不可变版本、实际观察及映射规则，不拥有可变企业归属、统一业务状态、跨来源currentVersion或资格裁定。旧 `platform_relation` 冻结为兼容观察，不再扩万能可空业务列；新原行保留JSON类型，旧类型损失记未知，不重算旧hash。

## 3. 正式出处、主体事实与输入血缘

### 正式公布与资格

最小链：正式文件内容版本 → 出处行原值/坐标 → 正式事件 → 有效资格周期。出处行拥有该次公布原名、原统代、原属地、附件/分节/名单序号及已核页码，指回原内容与归属依据。`record` 保留企业×称号×发布方兼容容器；其第一份原值或企业现名不能回填成所有年度事实。

稳定 `eventId/evidenceId` 继续定位，一个事件可有多份独立佐证。同内容改路径与增加独立出处是不同命令，不能覆盖第一路径或因事件存在而跳过新佐证。写接缝复用正式导入预检/提交、事件/出处更正，后续补明确追加语义；读接缝返回事件、各出处原值及版本，消费者不依赖新表布局。

原认定年、办理业务年、公布结论年、采集时间、维护年、本地到期年分别表达。复核 `event.year` 是被复核原认定年，`decidedYear` 是结论年；缺失未知，不能拿采集年或原认定年冒充结论年。事件身份不能只由类型/原认定年/批次确定：同2018批次在2021与2024的合法复核须共存；同一事项矛盾结论须明确待核，不能把结果值塞入唯一键假消重。

共用原认定周期的恢复/终止裁定，首次认定、复核计划、当前资格分别输出。2020认定→2023正式复核失败→2024仅复核通过、无重新认定，不能只取最后通过就自动恢复有效；具体冲突处置承接既有资格规则与专票，不在本ADR发明新规则。平台退回、终审不通过或目录消失不自动成为正式失效。

复用现有优质中小企业查询及三称号异步工作簿的资格读取，不新增第二套查询或资格writer。目录查询输出平台陈述，当前资格输出本地裁定，两者不得更名替代。

### 主体迁移与状态断言

主体领域拥有迁入、迁出、注销等独立断言：主体、事实类型、来源引用/原陈述、实际给出的发生或有效时点、确认状态及确认/替换/撤回历史。未知城市、称号、批次或时间不猜补，地名变化不是确认迁移。现用资料/别名复用企业资料PATCH及审计，不按字段新开接口。

差异决定引用多个有类型事实，拥有解释与措施的决定生命周期，不独占迁移事实。更名或“平台未更新”解释替换head不隐式撤销迁移，也不自动复活旧head中的迁移原因。后续投影区分原事实、确认、替换/撤回与有效性；资格读接缝只消费明确有效断言并返回依据。

### 文件、OCR与解析

文件领域区分稳定ID、路径、显示名和内容身份。同路径换字节不静默重指旧正式出处或沿用旧OCR/解析；保留旧依据，明确冲突和依赖失效。物理删除不能假装随DB回滚，恢复隔离/删除意图/最终回执另票处理。

血缘最少为：文件内容身份 → OCR原始采集及其输入/页 → 校对页修订 → 解析实际使用的页版本清单/文件内容身份 → 解析输出版本 → 正式入库引用。OCR采集raw与人工文本修订分开；只对实际使用的输入验版本，不强求全部文件全文水合。发布/保存重核输入与目标修订；单页版本或解析输出CAS不等于输入血缘。冲突保留编辑稿/识别结果，重读核实，不自动用最新输入覆盖。

文件维护、OCR页读写、解析维护继续作为稳定接缝，后续增量携带输入引用与校验结果。旧输入依据缺失记unknown，不用当前hash倒填旧输入。不引入通用依赖图、存储compiler或GC。

## 4. 决定、proof与旧引用不变量

- `queryId/relationId/sequenceNo`、业务ID/versionId、exportBatchId/exportRowId、eventId/evidenceId、correspondenceId、proofId、批次/回执/审计ID、文件ID和深链继续可定位。别名来源、差异evidence引用与任务分段也保留，不按裸业务编号改指/删观察。
- 原raw、正文、canonical内容、旧hash算法/值、sourceFingerprint、revision、plan/request绑定和审计保留；只追加明确版本的投影。旧类型不反推，不重算指纹使旧决定重新有效。
- 先按原规则限定企业/称号/角色/年度/时间/来源，再按业务身份组织观察。同版本或hash不把某观察的确认、驳回、解除、归属或proof传播到其他观察；当前投影不替换历史来源。
- 年度保留全部过程与唯一final的既有最新有效业务及明确结果规则。来源代次变更经113登记、114明确复核；proof范围/等价资格与确认/撤销审计不削弱，不从旧候选偷换授权。
- 更正、替换/撤回和确认走原子领域命令与审计；不产生第二个决定writer。同坐标异载荷明确冲突，同幂等键同载荷回原回执，整批失败不留部分业务写入。

## 7. expand–contract与验收顺序

1. **设计门禁**：确切head/tree经父安排的新鲜独立Spec与Standards审查均无阻塞。回执前依赖模型任务不解锁，局部正确性修复按票面可独立进行。
2. **先止损**：JSON类型、完整分页、同坐标异载荷、旧标签/读链、OCR并发/任务恢复各票修复，保留原FAIL/UNKNOWN，不以迁移掩盖。
3. **expand**：出处/事件身份/主体事实/输入血缘按依赖增量；平台先做一个来源专用存储+查询纵切，再以实证复用公共部分。保留旧字段/reader/inline，不设竞争决定writer；每个≤M切片独立PR。
4. **固定输入只读影子对照**：以后续单独授权的一致备份/隔离副本固定数据、规则、条件、时点、来源代次；旧/新reader只读同一输入，比较旧ID映射、行数/分页/筛选、字段/未知冲突、资格/final/proof及审计定位。已批准语义修复的差异单列留档，不把新reader自身当唯一oracle。投影写入在独立预检/提交阶段完成，影子阶段不写决定。
5. **逐消费者切换**：按14组切HTTP/MCP/页面/任务/导出/技能，登记未切项及旧调用；不兼容可退旧reader且旧ID可读。候选/年度不因迁移重新确认旧决定。
6. **contract另行授权**：消费者及历史引用迁完、有实际停用证明、可读回滚记录与独立授权后才讨论去旧字段/接口。本ADR不授权删表/原观察、清正文或历史重写，回滚不能恢复旧DB抹掉新提交。

后续验收优先公开HTTP/MCP最高接缝、隔离合成SQLite、原子失败/幂等回执与精确读回。真实备份需求先向父说明一致时点、来源、隔离路径、保护hash、读写方式及恢复条件，安排前不打开活动库。UI变更验收桌面/390px；导出异步下载后独立解析工作簿。只跑单worker定向测试；typecheck/build等重活先报父取得slot，全仓组合套件由父集成阶段串行安排。本票仅文档，上述运行验证均UNRUN，不借部署PASS。
