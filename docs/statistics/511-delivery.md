# 统计页业务口径与验证边界（#511）

统计页分为累计正式公布企业数、迁入/迁出/注销事实、年度有效企业数、当前有效企业区县分布。各区块的数字仅打开相同口径的企业明细，明细按需进入侧边抽屉，优先呈现统计概览。沿用现有组件、设计变量与表格规范，不引入新的设计系统。

## 读取边界

- 累计公布按企业与称号去重，以正式认定及出处为依据；后续失效不扣减累计数。身份歧义单列待核。平台记录、入库培育与单独复核不创造公布企业。
- 迁移和注销统计采用主体事实的当前有效修订，按每种事实的企业去重；发生年未知单列，不能用采集年替代。同一企业可发生迁出和迁入，不是互斥状态分布。
- 年度数量根据当前已录入证据重算，历史取上海年末，本年取当前评价日；不声称还原当年的数据库快照。资格、事实的发生时点与精度决定历史适用范围，待核与有效分开。
- 当前有效属地来自企业当前已确认属地，包括未知属地及独立管理区；每称号区县之和与同快照有效总数一致，不重建历史属地。
- 现行 v10 规则保持不变：旧迁入资格决定不恢复过期资格，迁入事实本身不授予称号，也不抵消现行读取中的迁出排除。
- 既有 `/api/stats` 及首次认定年份等消费者保持兼容。四个业务统计接口位于 `/api/statistics/`，汇总、明细及分页来自各自同一只读事务。

## 审核与回归

独立 Standards 与 Spec 审核分别发现共享表格使用、默认明细过长，以及已消解旧复核缺口在后续资格到期后重新成为待核的问题。已改用共享表格与 DisclosurePanel；新增公开 HTTP 回归证明旧缺口不在 2025/2026 年复活，真实未消解缺口仍待核。分页解析器重复仅为启发式建议，未发现行为错误，本轮暂缓提取共享控制器。

11 个限定测试文件共 94 个测试已获得通过证据，不能表述为单次全绿：实施者首次运行 93/94，旧 #305 用例超时，单文件重跑 3/3；集成首次运行 93/94，旧 bounded-http 导入夹具返回 503，单文件重跑 5/5。两次原始失败均保留。503 的具体原因未知，发生在未修改的导入链路、尚未执行新增统计读取；不能仅凭重跑成功断言根因。

最终界面微调后，四个统计 HTTP 文件再次执行，16/16 通过；类型检查与 diff-check 通过。桌面 1440×900、移动 390×844 已实际操作汇总下钻、年度空/待核结果、未知属地、迁移依据、自定义每页条数及翻页、键盘收起、首次失败、旧结果保留、延迟加载与重试恢复。年度表仅在表格容器内横向滚动，页面无横向溢出。全部使用隔离合成 SQLite，未访问生产业务数据。

未运行全量测试、生产构建、CI、部署、生产规模性能或正式来源完整性验收。独立审核后的修正由源代码核对、回归及实际操作验证，未再启动一轮独立审核。仓库没有 lint 脚本。历史失败、未知根因与未运行范围不会被后续通过覆盖。

## 用户回改：图形化概览，不使用表格

用户查看初版后明确否定视觉并要求重设计、不要表格。这一后续指令覆盖原先年度数值表的展示决定，全部统计读契约与资格规则继续沿用。

页面改为有品牌色阶的三称号大数卡、紧凑迁移指标带、年度趋势曲线与年份切换/精确数量、可切称号的区县条形排行。四类企业明细统一使用现有 Sheet 和列表，保留原有分页、出处、失败目标与旧结果来源；页面与抽屉均无表格。沿用原品牌 token，不改变全局导航或其他页面的组件。

本轮只修改展示层。类型检查、diff-check及桌面/390px实际画面和交互自查完成；未新增测试、未重跑业务全套或生产构建，也未将旧版的独立审核称为新界面的独立评审。初版重设计期间的样式热更新准备错误和两次模板类型错误保留在本地过程记录，修正后最终类型检查通过。

## 2026-11-06 真实业务副本性能优化

用户要求优化统计查询链路。已完成请求内分组、汇总与分页诊断分离及来源复验语句复用，公开 HTTP 年度639毫秒、区县399毫秒，13组原版响应深比较一致（除请求时间戳），118项相关回归通过。完整口径、环境、历史失败、证据与限制见 [性能验证](511-performance.md)。此轮不覆盖此前未运行的生产/CI/独立审核项目。
