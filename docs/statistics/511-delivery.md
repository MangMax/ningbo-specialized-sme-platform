# 统计页业务口径与验证边界（#511）

统计页分为累计正式公布企业数、迁入/迁出/注销事实、年度有效企业数、当前有效企业区县分布。各区块的数字仅打开相同口径的企业明细，明细按需进入侧边抽屉，优先呈现统计概览。沿用现有组件、设计变量与表格规范，不引入新的设计系统。

## 读取边界

- 累计公布按企业与称号去重，以正式认定及出处为依据；后续失效不扣减累计数。身份歧义单列待核。平台记录、入库培育与单独复核不创造公布企业。
- 迁移和注销统计采用主体事实的当前有效修订，按每种事实的企业去重；发生年未知单列，不能用采集年替代。同一企业可发生迁出和迁入，不是互斥状态分布。
- 年度数量根据当前已录入证据重算，历史取上海年末，本年取当前评价日；不声称还原当年的数据库快照。资格、事实的发生时点与精度决定历史适用范围，待核与有效分开。
- 当前有效属地来自企业当前已确认属地，包括未知属地及独立管理区；每称号区县之和与同快照有效总数一致，不重建历史属地。
- 现行 v10 规则保持不变：旧迁入资格决定不恢复过期资格，迁入事实本身不授予称号，也不抵消现行读取中的迁出排除。
- 既有 `/api/stats` 及首次认定年份等消费者保持兼容。四个业务统计接口位于 `/api/statistics/`，汇总、明细及分页来自各自同一只读事务。
