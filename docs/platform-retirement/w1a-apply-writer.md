# W1a explicit apply target writer

`lib/platform/apply-target-writer.ts` exposes `writeApplyTarget(db, input)` for an explicitly opened finalized-target transaction. It does not select a schema or open a database. A savepoint encloses record/version reuse, apply version and observation projections, observation, initial assignment, sealed rawFields/sourceText/canonical archives and relation alias allocation. Errors propagate; catching an error in an outer transaction cannot commit partial writer effects.

The caller must validate the current import contract, resolve a real existing apply collection and its position, and provide explicit command assignment provenance. This seam accepts materialized rows, not partial `reuseExisting` reference commands. For this seam, identical collection/sequence and identical materialized row/position/assignment replay without writes; differing payload rejects. Public omission/reference and ownership-changing commands still belong to W1b/W4 orchestration. Query aliases belong to collection creation; this writer allocates only relation aliases above the reserved frozen maxima. It neither creates collections nor infers ownership or historical confirmation times.

Source identity planning and hash serialization moved unchanged to `lib/platform/observation-plan.ts`; the legacy public writer imports/re-exports it. Shared source extraction is `source-extraction.ts`, used at ingestion and by T05b. The source-specific apply parser and seven-field legacy reconciliation intentionally retain their distinct year grammar. Raw JSON is serialized at ingestion; business readers will consume the persisted projections rather than reparse archives.

Finalized declarations and archive resolution live in `lib/platform/target-{schema,archive}.ts`; upgrade modules re-export them. They are explicit infrastructure, not registered ordinary expand declarations or runtime selectors. Ordinary CRUD uses Drizzle. The ordinary schema and final catalog are unchanged. Version canonical archive binding follows the existing trigger protocol: create version, bind and seal archive, then set canonicalArchiveId, all within the savepoint.

#716 runtime/initialization/worker refusal of finalized targets remains. Public preflight/commit/replay, collection/page/scope creation, 113 impacts, receipts, and removal of the old apply branch are not switched here. W1b/W4 and later R/H/C/Z work own those changes; this module is not a generic three-source writer. Actual historical migration, public cutover, complete W1/#706 acceptance, #705 performance recovery and B409 acceptance are not established by synthetic finalized SQLite tests.
