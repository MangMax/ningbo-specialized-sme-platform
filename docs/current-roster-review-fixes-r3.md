| 输入事实（Y 为执行年） | 周期裁定 / 聚合字面期望 |
| --- | --- |
| 每个原周期 (year,batch) 的 award/review | 全量收集，先逐周期裁定；失败/未知结果也必须进入，禁止只由 passed seed 缩减 |
| 有效 award，未到 anchor+3 | eligible；无需预先出现复核；award 时间沿用 decidedYear??year |
| 对应周期 passed（明确原年/批次/结论年，结论>=原年且<=Y），无未恢复失败 | 延续至结论年+3；到期当年 pending；同周期多次通过取延续锚点，不造首次年 |
| 无 award 的完整正式 passed；跨周期 passed 链 | 可以确证延续，firstYear=null；有旧 award 则保留该真实首次历史 |
| 对应周期 failed 后无新 award，后续无 passed | excluded；到期/失败不自动删除历史 |
| failed 后只有 passed（同年或较晚），无重新 award/正式更正 | pending，恢复矛盾待核；passed 不消除终止；较早 passed 后较晚 failed 则 excluded |
| 同周期真实后续 award，时间明确晚于失败 | 可恢复；同年 award/failed 无可证顺序 pending；正式更正以当前已更正事件事实重判，不从自由文本推断 |
| 新原周期 award / 旧周期失败 | 新周期可有效；旧周期晚失败不终止新周期。旧失败与新 award 同年仍保留“恢复顺序不明”；与新周期 passed 同结论年不是跨周期冲突 |
| 2018 failed2025 与2021 passed2025（两个周期均有 award） | eligible；不得用全历史同结论年匹配失败 |
| 同原年份多个 batch | 每批裁定且保留；没有明确唯一适用批次时 pending，尤其 passed + failed/无复核/缺结论，不能挑通过批次 |
| review 原年已知、批次未知或与未知批次 award 对应不明 | 该原年周期 pending；不得猜批次。仅完整新 award 且尚无 review 的缺批次不单独取消可确认资格（保留既有语义） |
| review 原年份未知 | pending；仅结论年明确早于后续真实新 award 才可让位，保留缺口备注；passed 不是恢复认定 |
| award 无可用日期 / review 无结论年、无结果、结论早于原年、未来原年或未来结论 | 影响当前周期则 pending；未知日期 award 无法确定属于旧历史，pending；已知旧周期缺口不冒充当前周期 |
| 旧 award + 独立 passed；同周期连续3次 passed；无award跨周期连续passed | 保持可确认资格 eligible（未到期时），首次历史分别保留旧 award / 真实award / 空 |

聚合顺序：1) 以原年份与批次建全量周期集合，未知原年份隔离为待核证据；2) 每周期检查时序/批次/结果缺口、同年矛盾、失败后恢复边界、三年到期，产出裁定；3) 在已裁定周期中按原年份选择当前候选，保留该原年全部批次，冲突/未决 pending；旧周期仅按明确新 award 恢复边界或未知原年适用性影响聚合，不按 review 的最大结论年跨周期覆盖；4) 原有身份/出处/主体事实检查继续适用。事件数组顺序、事件/出处 ID 的任意排列不改变分组或首次年。无正式出处的当前周期事件保持 pending，旧首次依据缺口留空。规则升级 v4；公开摘要继续原样识别 v1/v2/v3。
